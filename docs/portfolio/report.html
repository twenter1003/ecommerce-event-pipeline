B2C 이벤트 로그 데이터 파이프라인

숫자와 그림으로 보는 결과

REES46 이커머스 행동 로그 7개월치(2019-10 ~ 2020-04)로 만든 배치·레이크하우스·실시간 파이프라인의 측정값입니다. 그림마다 무엇을 보면 되는지와 숫자를 어떻게 셌는지를 함께 적었습니다. 표시에 마우스를 올리면 값이 보이고, "표로 보기"를 열면 그림의 숫자를 모두 볼 수 있습니다.

  • 410,325,314원천 이벤트 (213일)
  • 42분7개월 백필 (노트북, 동시 3)
  • 213 / 213GCP 결과가 로컬과 같은 날
  • 120 / 120강제 종료 뒤에도 배치와 같은 1분 윈도
  • 103,053배치와 똑같은 실시간 세션
  • 57자동 테스트

배치 적재와 품질 (1·2단계)

일 단위 멱등 적재, 품질 검사 8개, 7개월 백필. 동시 실행 수는 재서 정했다.

레이크하우스 모델링 (3단계)

Iceberg 위에 세션, 상품 이력(SCD2), 퍼널·코호트 마트를 만들었다. 원천 데이터의 함정 세 가지를 숫자로 찾았다.

GCP로 옮기기

같은 DAG를 Composer와 Dataproc으로 옮겨 213일을 돌렸다. 날짜별 행 수가 로컬과 모두 같았다.

실시간 (4단계)

Kafka로 이벤트를 다시 보내고 Spark Structured Streaming으로 1분 퍼널과 세션을 셌다. 결과는 배치와 윈도마다 대조했다.

데이터: REES46 eCommerce behavior data(재배포하지 않음). 그림은 저장소의 docs/portfolio/build_viz.py가 docs/portfolio/data/의 집계 CSV에서 만든다.
